LOCAL PIPELINE

运行链路

第一版先不在网页提交内容，所有输入和处理都通过 GitHub 与本地脚本完成。

  1. 把文章或对话放入 content/inbox。
  2. 本地执行 python3 scripts/process.py。
  3. 脚本读取 skills/current.md 并生成卡片。
  4. 结果写入 data 和 public/knowledge.json。
  5. 提交并 push 到 GitHub，网站自动展示最新知识库。
